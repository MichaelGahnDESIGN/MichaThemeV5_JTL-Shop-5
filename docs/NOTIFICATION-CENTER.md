# Notification Center

MichaThemeV5 stellt die Glocke dar. Für öffentliche und persönliche Daten muss das mitgelieferte Plugin `MichaThemeV5NotificationCenter` installiert sein; ohne Plugin zeigt das Theme absichtlich nur einen leeren Zustand. Die Plugin-Tabellen sind nach Shop-Kunde getrennt. Vor der produktiven Installation muss die SQL-Migration in einer Testumgebung geprüft werden.
