# MGD Notification Center für JTL-Shop 5

Zeigt im Shop eine Glocke mit Meldungen. Es gibt öffentliche Meldungen für alle Besucher und persönliche Meldungen für einzelne Kunden.

## Installation

1. ZIP aus dem Release herunterladen.
2. Im JTL-Backend unter Plugins > Plugin-Verwaltung hochladen und installieren.
3. Im Plugin-Backend den Reiter „Meldungen“ öffnen und die erste Meldung schreiben.

## Reiter im Plugin

- **Meldungen:** schreiben, bearbeiten, archivieren.
- **Übersicht:** Info, Updates, Weitere Plugins und der Schalter „Installation melden“.
- **Einstellungen:** Anzahl der Meldungen im Panel und Icon der Glocke.
- **Weitere Plugins:** andere MGD-Plugins für JTL-Shop.

## Datenschutz

Das Plugin meldet sich höchstens einmal am Tag bei theme.michael-gahn.de. Gesendet werden nur Plugin, Version, Shopsystem, Domain und eine zufällige ID. Der Schalter „Installation melden“ ist in der Übersicht und lässt sich abschalten. Meldungen und Empfänger bleiben in deiner Shop-Datenbank.
