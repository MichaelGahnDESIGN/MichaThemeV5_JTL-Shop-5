# MichaThemeV5 Begleitplugin (JTL-Shop 5)

Das Plugin bringt das Template MichaThemeV5 in den Shop und hat eine Verwaltung mit den Reitern Übersicht, Einstellungen, Lizenzen, Weitere Plugins, Info und Demo-Inhalte.

## Installation

1. Plugin-ZIP im JTL-Admin unter „Plugins“ hochladen und installieren.
2. Im Reiter „Info“ das Template kopieren und aktivieren.

## Datenschutz

Das Plugin meldet sich höchstens einmal am Tag bei theme.michael-gahn.de. Gesendet werden nur Plugin-Name, Version, Shopsystem, die Domain deines Shops und eine zufällige Installations-ID. Keine Kundendaten, keine Bestellungen.
Die Meldung läuft nur im JTL-Admin, nie im Shop bei deinen Besuchern. Abschalten kannst du sie im Reiter „Übersicht“ beim Haken „Installation melden“. Das Plugin funktioniert dann genauso weiter.
